## Archived: 2026-11-02
* The project designs interface with standard medical tubing, which uses a 22mm ISO 5356-1 standard outer diameter.
* To compile OpenSCAD (.scad) source files to STL format, use the command: 'openscad -o <output.stl> <input.scad>'.
* The repository contains 3D printed components for the Tetra PAPR (Powered Air-Purifying Respirator), with existing models primarily stored in the STLs/ and STEP/ directories.
* OpenSCAD is the preferred tool for creating new 3D models and can be installed in the environment via 'sudo apt-get update && sudo apt-get install -y openscad'.
